⚙️ CONFIG DECLARATIVA, QUEDÁNDOTE EN EL ECOSISTEMA PYTHON

En el mundo low-code cambias de entorno cuando quieres configurar: un panel visual, un YAML gigante, una base de datos propietaria. Todo fuera de tu código, todo difícil de versionar.

Con wpipe, la configuración vive en el mundo del desarrollador: cargas tu flujo y tus parámetros sin abandonar Python.

📋 CONFIGURACIÓN YAML + CÓDIGO

Define los valores de los parámetros en un pipeline.yml, como pipeline_name, verbose, retry_count y parámetros personalizados, y tu pipeline los consume en tiempo de ejecución mientras la lógica permanece en código.

🎯 POR QUÉ GANA LA CONFIG CODE-FIRST

Aspecto | Panel visual | Config en código (wpipe)
Versionado | Sin diffs | Flujo Git nativo
Revisión | Clics a ciegas | Pull request
Portabilidad | Depende del proveedor | Un YAML o archivo Python
Salida del proveedor | Traumática | Trivial (pip install)

💡 EL PUNTO CLAVE

No eliges entre código y configuración. Eliges dónde vive la fuente de verdad: en tu repositorio, revisable, testeable, portable.

La soberanía de tu automatización empieza por meterla en Git.
