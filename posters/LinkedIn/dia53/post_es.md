📄 LOGS, MÉTRICAS, AUDITORÍAS: EXPORTA TU PIPELINE

Un pipeline resiliente es inútil si luego no puedes demostrar qué pasó: para una auditoría, un informe de cumplimiento o comparar la evolución del rendimiento entre ejecuciones.

Con wpipe, el historial se persiste por defecto. Y cuando lo necesitas, lo exportas en segundos.

📤 EXPORTAR EN POCAS LÍNEAS

Usa el exporter sobre tu base de datos de tracking para obtener logs de ejecución completos como JSON o CSV, además de estadísticas consolidadas: tasa de éxito, duración media, por paso.

🗂️ LO QUE OBTIENES

Formato | Uso
JSON | Integraciones, APIs, sistemas externos
CSV | Hojas de cálculo, informes para stakeholders
Estadísticas | Tasa de éxito, duración media, por paso

🧠 POR QUÉ EXPORTAR ES ESTRATÉGICO

1. Auditoría real: no creo que funcionó, sino aquí está el log.
2. Análisis de rendimiento: compara métricas entre versiones del pipeline.
3. Interoperabilidad: tus datos de ejecución viajan donde los necesites.

La orquestación moderna no termina cuando el pipeline acaba: termina cuando puedes explicar qué hizo.
